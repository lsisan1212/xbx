[00:00-10:00]学习定位与前置准备

直播面向量化新手，核心目标是帮助新手规划凌烟阁策略回测框架的学习路径，完成团队作业，避免老学员重复学习。需提前准备策略认知、框架工具、数据与策略包。

點擊展開詳情

1. 策略认知：了解凌烟阁1（趋势类个股择时）、1.1（反转类个股择时）、1.2（篡改K线优化择时），以及现金流选股、偏科生选股（多因子随机组合）策略；

2. 框架工具：下载回测框架（2.3.3常用版/2.4.0新增隔日开盘价版本）、网页版（0.4.6，五一节后适配2.3.3/2.4）、实盘客户端（3.6.4稳定版）；

3. 数据准备：通过客户端订阅下载7类基础数据（指数历史数据、小时数据、股票小时数据、全息数据、公告标题汇总、5分钟数据、财务数据）；

4. 策略包：下载3个精星随机策略包（小市值基础、凌烟阁小市值+择时、中市值零因子策略）。

[10:00-25:00]一阶：新手筑基（网页版入门）

核心目标是完成官方策略的导入、组合与回测，掌握框架基础使用，适合对代码不熟悉的新手，为团队作业打基础。

點擊展開詳情

1. 学习目标：下载并组合框架与网页版、导入策略包、用网页版组合官方策略、完成回测并导入客户端；

2. 操作流程：将网页版复制到框架目录 → 设置网页版数据路径（与客户端存储路径一致） → 导入策略包（zip格式，含config、因子、策略文件） → 选中策略一键回测；

3. 策略组合：通过「保存为模板」功能，将多个官方策略（如小市值+中市值）保存为自研模板，再组合成新策略（五一节后修复适配bug）；

4. 回测结果查看：主图看资金曲线与回撤面积，右侧看累计净值、年化收益、最大回撤等指标，下方看选股数量与策略参数。

[25:00-40:00]二阶：入门金丹（工具深化与作业一）

核心是掌握参数遍历、回测实盘对比工具，完成团队作业一（实盘对比），理解策略细节与优化方向。

點擊展開詳情

1. 参数遍历：网页版点击「便利」→ 设置择时参数（如CCI、N日最高收盘价）→ 生成热力图/参数平原图，找到最优参数（官方参数未必最优）；

2. 回测实盘对比（作业一）：下载「选股选币对比统一版」脚本 → 收集回测选股结果与缓存文件 → 收集实盘选股结果与运行缓存 → 配置工具路径（模式设为stock）→ 执行对比，差异可手动删除股票模拟；

3. 资金曲线对比：实盘资金曲线通过同花顺导入券商账号查看，与回测曲线对比仓位与收益；

4. 新功能预告：下下个星期将上线回测结果导航栏，支持股票买卖时机查看，替代策略查看器。

[40:00-60:00]三阶：进阶元婴（代码版精通与作业二/三）

核心是掌握代码版框架使用，理解因子与策略逻辑，完成作业二（指标复现）与作业三（策略模改），达到框架使用毕业水平。

點擊展開詳情

1. 代码版基础：Config文件分5部分（回测配置、数据配置、策略配置、模拟交易配置、其他配置），重点关注回测时间与数据路径；

2. 策略配置结构：含策略名称（与文件名一致）、基础参数（Offset、权重、选股数量、换仓模式）、选股逻辑、过滤逻辑、个股择时逻辑（stock timing list，支持Bar and参数）；

3. 策略组合：代码版直接复制粘贴多个策略，用逗号分隔，调整权重分配（如0.4+0.3+0.3）；

4. 代码版参数遍历：使用「寻找最优参数」脚本 → 复制策略配置 → 设置参数变量池 → 替代对应参数 → 运行后查看Excel结果与热力图；

5. 作业二/三完成：复制现有因子/信号文件 → 喂给AI解读逻辑 → 导入研报公式 → 让AI生成新因子/信号文件 → 放入对应目录 → 模改策略完成作业三（一鱼两吃）。

[60:00-75:00]因子分析与核心工具解读

通过单因子/复合因子分析，深入理解策略有效性，掌握核心分析工具的使用逻辑，重点关注IC图与分箱图。

點擊展開詳情

1. 单因子分析：重点看IC图（趋势单调性证明因子有效性，避免失效）与分箱图（选股一致性，单调排序说明选股能力强）；

2. 复合因子分析：在Other factor list中写入核心因子名称 → 配置过滤条件 → 定义复合因子名称 → 运行分析（新手建议先分析单因子）；

3. 工具使用原则：分析目标是因子而非策略，建议用简单策略做分析，复杂策略分析需写大量逻辑，操作繁琐；

4. 分域逻辑：分域即过滤逻辑，通过筛选条件（如净利润前80%、收盘价＜20元）形成具有共同特点的选股池（如低价股域、高净利润域）。

[75:00-90:00]常见问题与实操注意事项

汇总新手在框架使用、策略组合、作业完成中的高频问题，明确操作规范与避坑要点。

點擊展開詳情

1. 文件名与格式：config文件只要是py格式且符合规范，名称可自定义；网页版无需导入因子/信号文件，直接放在对应目录即可调用；

2. 策略组合与对比：同一策略组内的多个策略可一起回测，选股结果会合并，支持回测实盘对比，且会标注股票来源策略；

3. 参数与权重：择时参数建议覆盖3个（邢大建议），权重分配趋势类60%+反转类40%（减小回撤），多个策略权重和为1，便于直观理解；

4. 实盘相关：综合策略库从3.6.0版本开始支持，可组合多个策略组；Actual timing择时回测可用，实盘可用性需确认；持仓周期最长为月，无法调成3个月；

5. 过滤逻辑：目前为并列关系（and结构），无先后顺序，功能建议可在攻略帖下留言反馈。

明确学习资源获取路径与问题反馈方式，帮助新手持续跟进框架更新与功能优化。

底層邏輯與框架

點擊展開詳情

1. 核心思維模型：「三阶修仙」学习路径

以修仙进阶为隐喻，将框架学习分为筑基（网页版入门）、金丹（工具深化）、元婴（代码版精通）三个阶段，符合新手从易到难的认知规律。核心逻辑是「工具熟悉→功能深化→逻辑理解」，先通过网页版降低入门门槛，再通过代码版提升灵活性，最终实现独立实操与创新。

2. 因果關係鏈

  • 因：新手面临框架功能复杂、策略逻辑不清晰、作业不知如何下手等问题；
  • 果：通过分阶段学习，先掌握基础工具使用，再深化核心功能，最后理解底层逻辑，逐步解决实操难题；
  • 递進關係：工具熟悉（网页版回测）→ 功能深化（参数遍历、实盘对比）→ 逻辑理解（代码版、因子分析）→ 独立创新（作业复现、策略模改），每一步都为后续学习奠定基础。

3. 關鍵隱喻與案例

• 隱喻：将框架学习比作「修仙」，筑基（基础工具）、金丹（功能掌握）、元婴（逻辑精通）对应不同学习阶段，让新手有明确的目标感；策略组合比作「搭积木」，通过模板保存与复制粘贴，灵活组合不同策略；

• 案例：小市值+中市值策略组合演示中，通过网页版保存模板、代码版复制粘贴两种方式，实现多策略组合回测；作业二DPO因子复现中，利用AI解读现有因子逻辑，导入研报公式生成新因子，降低新手编程门槛。

實作步驟 Checklist

  • 步驟1：前置準備（筑基階段）

    工具：电脑、浏览器、百度网盘；参数：回测框架2.3.3、网页版0.4.6、客户端3.6.4、3个精星随机策略包；卡关点：客户端数据订阅需确保7类基础数据齐全，下载时间约1小时

  • 步驟2：網頁版入門（筑基階段）

    工具：框架+网页版组合；操作：设置数据路径 → 导入策略包 → 组合官方策略（保存模板）→ 一键回测；卡关点：数据路径需与客户端一致，否则无法读取数据

  • 步驟3：參數遍歷與優化（金丹階段）

    工具：网页版参数遍历功能；操作：点击「便利」→ 选择择时参数（如CCI、N日最高收盘价）→ 设置参数范围 → 生成热力图 → 选择最优参数；卡关点：避免同时遍历过多参数，否则运行时间过长

  • 步驟4：回測實盤對比（作業一）

    工具：选股选币对比统一版脚本；操作：收集回测/实盘选股结果与缓存 → 配置工具路径 → 执行对比 → 同花顺查看实盘资金曲线；卡关点：实盘需先运行产生交易记录，否则无法对比

  • 步驟5：代碼版基礎配置（元嬰階段）

    工具：代码编辑器、框架代码版；操作：理解Config文件结构 → 配置回测时间与数据路径 → 复制粘贴组合策略 → 调整权重；卡关点：策略名称需与文件名一致，否则无法调用

  • 步驟6：代碼版參數遍歷（元嬰階段）

    工具：寻找最优参数脚本；操作：复制策略配置 → 设置参数变量池 → 替代对应参数 → 运行查看Excel结果与热力图；卡关点：参数变量需与策略中参数名称一致

  • 步驟7：因子與信號文件生成（作業二）

    工具：AI工具（GPT/Cloud等）、代码编辑器；操作：复制现有因子/信号文件 → AI解读逻辑 → 导入研报公式 → AI生成新文件 → 放入对应目录；卡关点：生成后需请教林奇助教或夏普船长验证正确性

  • 步驟8：策略模改與作業三完成（元嬰階段）

    工具：代码编辑器、框架代码版；操作：使用作业二生成的因子/信号 → 模改现有策略 → 配置参数 → 回测验证；卡关点：模改时注意保持策略结构完整性，避免语法错误

  • 步驟9：復合因子分析（進階優化）

    工具：单因子分析工具；操作：写入核心因子名称 → 配置过滤条件 → 定义复合因子 → 运行分析 → 查看IC图与分箱图；卡关点：因子名称需与运行缓存中一致，否则无法计算

  • 步驟10：問題反饋與框架更新跟進

    工具：论坛攻略帖；操作：记录使用中的bug/建议 → 在攻略帖评论区留言 → 定期查看攻略更新；卡关点：反馈时需附上截图与详细描述，便于官方复现与解决

AI 補充建議

【AI 建議】 新手优先使用网页版完成基础回测与策略组合，待熟悉流程后再切换到代码版。代码版学习可从修改现有策略参数入手，逐步过渡到因子与信号文件编写，降低学习门槛。
【AI 提醒】 客户端数据下载时需确保网络稳定，7类基础数据缺一不可，否则会导致回测失败；网页版与客户端跑出来结果不一致时，优先检查数据路径与策略配置是否一致，或查看日志反馈给林奇助教。
【AI 建議】 作业二因子复现时，选择简单的单因子公式（如DPO）入手，复杂因子可拆分为多个步骤让AI生成，生成后需手动检查语法错误（如import语句是否缺失），避免直接运行报错。
【AI 提醒】 参数遍历时建议控制参数数量（2-3个为宜），过多参数会导致运行时间过长；权重分配时尽量明确比例（如0.4+0.3+0.3），避免全写1导致比例计算繁琐。
【AI 建議】 实盘对比时若没有差异，可手动删除回测结果中的部分股票模拟差异，让作业内容更丰富；同一策略组内组合多个策略时，建议控制数量在3-4个以内，避免选股结果过于分散。
【AI 提醒】 框架功能建议（如过滤逻辑先后顺序）可在攻略帖下集中留言，官方会根据反馈优先级优化；使用代码版时建议备份原始Config文件，避免魔改错误后无法恢复。
