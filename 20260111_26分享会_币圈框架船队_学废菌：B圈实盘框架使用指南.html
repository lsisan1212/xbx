前置准备：预备知识与工具清单

点击展开详情

1. 必备预备知识

  • 币圈基础：学习预备课程，了解现货（做多）、合约（多空双向）、统一账户与普通账户区别、API Key与密钥获取；
  • 框架基础：熟悉回测框架使用，掌握Config配置、因子库/截面因子库/仓位管理文件导入逻辑；
  • 学习资料：参考分享会"币圈新人准备工作汇总"帖子（含注册、入金、技术访问等），遇到问题咨询灵奇助教。

2. 核心工具清单

  • 框架代码：
    • 网页版：实盘网页版部署脚本（0.5.1版本，仅1个sh文件）；
    • 代码版：实盘框架1.3.11 + 数据中心1.1.6（Coin Real Time Data）；
    • 辅助文件：部署命令行TXT（含环境配置脚本，复制粘贴即可）。
    • 服务器工具：Termius（免费，支持FTP文件上传与命令行登录，二合一功能）；
  • 其他工具：谷歌身份认证器（动态密码生成，用于网页版登录）、企业微信（接收交易日志与资金曲线）。

3. 关键概念预习

  • 分钟偏移：用于一台服务器跑多个子账户，避免冲突，最多支持12个（0/5/10...55分钟）；
  • BNB燃烧：用BNB抵扣手续费可享折扣（合约9折、现货75折），框架可自动购买BNB；
  • 实盘模式：Debug（测试，仅选币不画图）、Simulate（模拟，算资金曲线不下单）、None（实盘，真实交易）；
  • K线数量计算：普通因子取参数值，截面因子需参数值×2+冗余（如360×2+100=820）。

服务器准备：选购与环境部署

点击展开详情

1. 服务器选购要点

  • 推荐厂商：腾讯云（性价比最高）、阿里云、UC Cloud；
  • 配置要求：境外服务器（东京/香港/新加坡，优先东京，靠近币安服务器）、2核4G、硬盘≥50G、Ubuntu系统；
  • 价格参考：腾讯云199元/年，UC Cloud 344元/年（新用户），阿里云78元/月；
  • 核心原因：币圈7×24小时交易，服务器稳定性/安全性优于本地电脑，境外服务器访问币安速度更快。

2. 环境部署步骤（代码版必备，网页版自动部署）

  • 基础环境：通过部署脚本安装Miniconda（轻量化Anaconda）、Python 3.12虚拟环境、必要三方库；
  • 工具安装：安装PM2（进程守护，自动重启崩溃脚本）、浏览器（用于生成资金曲线）、中文字体（避免乱码）；
  • 虚拟内存：建议设置（网页版自动提示，代码版需手动配置），提升服务器运行稳定性；
  • 防火墙设置：开放网页版端口（如9900），否则无法访问网页管理界面。

3. Termius使用指南

  • 连接服务器：输入IP、端口、用户名、密码，建立SSH连接；
  • 文件上传：通过SFTP功能，左侧本地文件→右侧服务器目录，右键复制即可；
  • 命令行操作：支持Ctrl+Shift+C/V复制粘贴，执行部署脚本与启动命令。

网页版实盘框架：新手友好，一键部署

点击展开详情

1. 核心优势与适用人群

  • 优势：操作简单（点点鼠标完成部署）、迁移方便（服务器到期一键迁移）、策略导入快捷（直接导入回测Config）；
  • 局限：灵活性低，无法自定义代码，部分参数不可修改；
  • 适用人群：新手、懒人、无需复杂自定义的用户。

2. 部署与配置步骤

  1. 上传脚本：将网页版部署脚本（Deploy_Chronos.sh）通过Termius上传到服务器；
  2. 授权执行：执行命令chmod +x Deploy_Chronos.sh（添加可执行权限），再执行./Deploy_Chronos.sh（自动部署环境）；
  3. 记录链接：部署成功后生成网页访问链接（含IP、端口、随机密码），建议收藏；
  4. 登录认证：
    • 第一步：同意开源声明，获取GitHub代码库中的验证码，填入后进入；
    • 第二步：用谷歌身份认证器扫描二维码，生成动态密码登录；
    • 第三步：微信扫码绑定身份，享受彩虹数据服务。

3. 数据中心配置（关键）

  • 历史数据小时数：根据策略最大因子参数设置（截面因子需×2+冗余），默认2000小时足够；
  • 数据API：建议勾选彩虹数据服务，与币安数据形成双备份，提升稳定性；
  • 分钟偏移：设置需与后续账户配置一致（如0/15分钟），支持多账户分开运行；
  • 启动运行：设置完成后点击启动，通过"查看运行日志"确认数据下载正常。

4. 账户与策略配置

  1. 新增账户：填写账户名称、类型（普通/统一）、分钟偏移、K线数量、杠杆、黑名单等基础参数；
  2. 关键设置：
    • BNB燃烧：勾选后自动用BNB抵扣手续费，自动购买11U BNB（可修改金额）；
    • 保证金设置：默认用USDT（填写1），支持多稳定币组合（如0.5 USDT + 0.5 USDC）；
    • API配置：填写币安API Key与密钥，实盘交易必备。
  3. 导入策略：上传回测框架的Config文件、因子库（Factors）、截面因子库（Sections）、仓位管理文件（Positions）；
  4. 模式选择：Debug（测试）→ Simulate（模拟）→ None（实盘），逐步验证策略有效性。

5. 三种交易模式详解

  • Debug模式：仅验证选币逻辑，输出选币列表，不生成资金曲线，不下单；
  • Simulate模式：计算资金曲线并推送至企业微信，不下单，用于验证策略历史表现；
  • None模式：真实下单交易，需确保API配置正确、资金充足，建议先小资金试错（2000U以内）。

代码版实盘框架：高扩展性，自定义灵活

点击展开详情

1. 核心优势与适用人群

  • 优势：支持代码自定义（如修改下单逻辑、添加特殊过滤）、多账户多策略同时运行、参数配置更细致；
  • 局限：部署步骤繁琐，需一定命令行操作基础；
  • 适用人群：有代码基础、需要个性化需求的高阶用户。

2. 文件结构解析

  • 核心目录：
    • Account：存放子账户Config（每个PY文件对应一个账户，不含下划线才会被识别）；
    • Factors/Sections/Positions：因子库、截面因子库、仓位管理文件（从回测框架复制）；
    • Call：执行数据整理、因子计算、选币的核心脚本；
    • Example：普通账户/统一账户Config模板，含完整参数说明；
    • Startup.json：控制启动脚本（Startup.py/Monitor.py/DeList.py）的路径与日志配置。
    • 关键文件：
    • Config.py：框架全局配置（数据路径、企业微信机器人、实盘模式）；
    • Startup.py：启动实盘交易的主脚本；
    • Monitor.py：防止策略爆仓的监控脚本；
    • DeList.py：防止下架币冲击的防护脚本。

3. 核心配置步骤

  1. 数据中心配置：
    • Config设置：填写K线数量、企业微信机器人链接、彩虹API开关、分钟偏移（单偏移需加逗号，如[0,]）；
    • 上传启动：将数据中心文件上传到服务器，激活虚拟环境后执行python Real_Time_Data.py测试，再用pm2 start Real_Time_Data.py后台运行。
    2. 账户Config配置：
    • 账户设置：填写API Key、密钥、账户类型、分钟偏移、最小下单量（现货10U/合约5U）、BNB燃烧开关；
    • 策略设置：导入回测框架的策略配置（子策略池、选币数量、过滤条件等），设置所需K线数量。
    框架Config配置：
    • 数据路径：复制数据中心的data目录路径，确保框架能读取数据；
    • 实盘模式：设置为"Debug"/"Simulate"/"None"，与网页版一致；
    • 企业微信机器人：填写链接，接收全局报错信息。
    Startup.json配置：填写三个核心脚本的路径与日志路径，支持删除不需要的脚本（如Monitor.py）。

4. 启动与监控

  • 测试启动：执行python Startup.py，验证选币与资金曲线计算是否正常；
  • 后台启动：执行pm2 start Startup.json，通过pm2 list查看脚本运行状态；
  • 日志排查：若运行异常，下载框架目录下的日志文件，发给灵奇助教协助排查；
  • 多账户运行：在Account目录添加多个Config文件，设置不同分钟偏移，即可实现多账户同时运行（最多12个）。

关键操作：策略迁移与风险控制

点击展开详情

1. 策略从回测到实盘的迁移

  • 网页版：直接上传回测框架的Config、Factors、Sections、Positions文件，框架自动适配；
  • 代码版：将回测框架的对应文件复制到实盘框架的同名目录，修改Account中的策略配置，确保参数一致；
  • 选币策略适配：实盘框架支持选币策略，会自动转换为cap_ratio=1的仓管策略运行。

2. 资金与风险控制要点

  • 资金要求：根据选币数量计算（1个币≈10U，50个币需500U以上，建议1000U起投）；
  • 仓位管理：实盘前先设置杠杆为0，清空持仓后再切换模式，避免强制平仓；
  • 测试流程：先Debug模式验证选币逻辑→再Simulate模式观察资金曲线→最后None模式小资金实盘；
  • 服务器隔离：测试与实盘建议使用不同服务器，避免测试代码影响实盘运行；
  • 策略风险：基础策略长期表现不佳，仅适合小资金试错（2000U以内），需等待分享会官方策略。

3. 常见问题解决

  • 网页版无法访问：检查服务器防火墙端口是否开放，链接是否正确（含密码部分）；
  • 数据下载失败：确认彩虹API已勾选，网络连接正常，查看数据中心运行日志；
  • 资金曲线乱码：安装中文字体，代码版需手动配置字体路径，网页版自动处理；
  • 多账户冲突：确保每个账户的分钟偏移不同，避免同一时间计算选币；
  • BNB燃烧失效：检查账户中有足够USDT，确保已勾选"BNB燃烧"选项。

2. 进阶使用技巧

  • 数据共享：同一服务器上，代码版可直接读取网页版的数据中心数据（只需配置正确数据路径）；
  • 多模式共存：网页版与代码版可安装在同一服务器，但需确保子账户分钟偏移不冲突；
  • 策略组合：代码版支持在一个账户中运行多个子策略，通过分钟偏移分开执行，提升资金利用率；
  • 下单逻辑：实盘框架默认市价下单，进阶用户可参考"币圈实盘框架下单逻辑解析与升级"帖子修改下单方式；
  • 框架升级：网页版支持在线更新，代码版需下载最新框架文件，覆盖旧文件后重新配置。

3. 后续学习方向

  • 官方策略：等待分享会新策略上线，学习从回测优化到实盘部署的完整流程；
  • 自定义开发：代码版用户可学习修改因子逻辑、添加特殊过滤条件、优化下单算法；
  • 多交易所适配：OKX交易所需下载专用实盘框架，网页版暂不支持；
  • 监控与告警：完善企业微信机器人配置，实时接收策略报错、资金曲线、交易记录。

🔍 底层逻辑与框架

点击展开详情

1. 核心思维模型

• 分层部署模型：网页版（低门槛入门）与代码版（高阶扩展）分层设计，适配不同用户需求，兼顾易用性与灵活性；

• 稳定性优先模型：通过服务器部署、双数据备份（彩虹+币安）、PM2进程守护、虚拟内存扩展，全方位保障实盘稳定性；

• 渐进式测试模型：Debug→Simulate→None三阶段测试，从逻辑验证到模拟运行再到真实交易，逐步降低实盘风险；

• 复用回测逻辑模型：实盘框架直接复用回测框架的Config、因子库等文件，避免重复配置，实现从回测到实盘的无缝衔接。

2. 因果/递进关系

• 币圈7×24小时交易→本地电脑稳定性不足→需使用云服务器→服务器需境外部署（靠近币安）→提升交易时效性（因果链条）；

• 新手缺乏代码基础→需要低门槛工具→网页版框架一键部署→满足基础实盘需求→高阶用户需要自定义→代码版框架提供扩展能力（递进关系）；

• 实盘风险高→需分阶段测试→Debug模式验证逻辑→Simulate模式观察曲线→None模式小资金试错→降低亏损概率（递进关系）；

• 策略参数复杂→截面因子需更多数据→K线数量计算为参数×2+冗余→数据中心提前下载足够数据→框架正常运行（因果链条）。

3. 关键隐喻与案例

• 隐喻1：网页版=自动挡汽车（简单易操作，适合新手），代码版=手动挡汽车（操控灵活，适合老司机），两者均能到达目的地（实盘交易），适配不同驾驶水平；

• 案例1：某新手用户通过网页版框架，1小时完成部署，导入回测策略后启动模拟运行，成功观察到低价币近期上涨的资金曲线；

• 案例2：某高阶用户通过代码版框架，自定义添加止损逻辑，同时运行3个不同分钟偏移的子账户，实现多策略分散投资；

• 隐喻2：服务器=实盘交易的"机房"，Termius=连接机房的"钥匙"，框架=交易的"核心设备"，三者缺一不可，共同支撑实盘运行；

• 案例3：25年10月11日币圈异常行情中，选择东京服务器的用户因网络稳定，实盘未受明显影响，验证了服务器选址的重要性。

代码版框架部署与配置（高阶用户）
  1. 上传框架文件：将实盘框架与数据中心文件通过Termius上传到服务器，分别创建目录存放；
  2. 配置数据中心：

  3. 配置账户Config：
    • 参考Example目录模板，创建子账户Config文件（不含下划线）；
    • 填写账户信息、API Key、策略配置、所需K线数量；
    • 复制回测框架的Factors/Sections/Positions文件到对应目录。

⚠️ 卡关点：账户Config文件名不能含下划线，否则框架无法识别；数据路径需准确，否则框架无法读取行情数据导致报错。
实盘运行与风险控制
  1. 阶段一：Debug模式测试（1-2天）
    • 验证选币逻辑：确认选币结果与回测一致，无漏选/错选；
    • 排查报错：若运行异常，查看日志文件，解决参数配置或数据问题。
  2. 阶段二：Simulate模式模拟（3-5天）
    • 观察资金曲线：确认策略表现与预期一致，无异常回撤；
    • 优化参数：根据模拟结果调整策略参数（如选币数量、过滤条件）。
  3. 阶段三：None模式实盘（小资金）
    • 资金准备：投入2000U以内资金，避免重仓风险；
    • 切换模式：将实盘模式改为"None"，重启框架；
    • 实时监控：通过企业微信接收资金曲线与交易记录，每日查看运行日志；
    • 风险控制：若出现大幅回撤，及时设置杠杆为0，清空持仓排查问题。
  4. 进阶优化：
    • 多账户运行：添加多个子账户Config，设置不同分钟偏移；
    • 策略组合：在一个账户中运行多个子策略，提升资金利用率；
    • 框架升级：定期更新框架文件，适配新策略与功能。
⚠️ 卡关点：实盘前务必确认API Key权限正确（开启交易权限），资金充足；切换模式前需清空持仓，避免强制平仓风险。

💡 AI 补充建议与提醒

【AI 提醒】新手优先选择网页版，避免初期挫败感
代码版部署步骤繁琐，需命令行操作与基础代码知识，新手直接上手易出错；网页版一键部署、图形化操作，1小时即可完成从部署到测试的全流程，建议新手先通过网页版熟悉实盘逻辑，再逐步过渡到代码版。
【AI 建议】服务器配置宁高不低，优先保障稳定性
虽然2核4G服务器可满足基础需求，但如果需同时运行多个账户或复杂策略，建议选择4核8G配置；硬盘选择≥60G，避免数据存储不足；服务器到期前提前备份数据与配置文件，防止数据丢失。
【AI 提醒】严格遵循三阶段测试流程，切勿跳过模拟直接实盘
部分用户急于实盘赚钱，跳过Debug或Simulate模式，直接启动真实交易，易因参数配置错误、选币逻辑异常导致亏损；建议至少运行3天模拟模式，确认资金曲线与回测预期一致后，再用小资金试错。
【AI 建议】善用辅助工具与社区资源，减少踩坑
Termius的SFTP功能可快速上传文件，避免手动输入命令出错；遇到问题先查看攻略帖（含详细步骤与截图），再咨询灵奇助教或群内老同学，他们已踩过大部分坑，能快速提供解决方案；定期关注分享会直播，学习新功能与优化技巧。
【AI 提醒】实盘策略需动态调整，避免长期单一策略
币圈市场风格变化快，单一策略可能短期有效但长期失效（如基础低价币策略近期上涨但长期表现不佳）；建议实盘后定期复盘，结合市场环境调整策略参数，或添加多个策略组合运行，降低单一策略风险；等待分享会官方策略上线后，及时替换基础策略，提升实盘收益。
