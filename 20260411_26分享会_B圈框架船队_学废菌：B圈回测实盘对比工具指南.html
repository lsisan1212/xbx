  • 回测框架：≥1.4.3（支持生成选币结果CSV）

  • 数据中心：≥1.1.11（避免币种对不上问题）
  • 网页版：回测网页版≥0.1.7/0.2.0，实盘网页版≥0.5.2（含新参数设置）

3. 策略包准备

  • 官方策略：下载沧浪亭26年V2版精心随机策略包
  • 自定义策略：从实盘account目录复制Config文件到回测框架，确保配置一致

数据准备关键细节（时差+偏移处理）

点击展开詳情

1. 数据时差核心规则

  • 回测数据：网页版下载数据截止时间为每日UTC 23点（北京时间次日7点），比实盘晚6-8小时
  • 实盘数据：ZIP包为北京时间每日更新，保存过去7天数据，需手动下载到回测框架data/选币对比目录
  • 分钟偏移数据：需手动下载（支持365天数据，每日更新），每7天下载一次，适配分钟偏移策略对比

2. 数据对齐要求

实盘需提前跑1.5-3天，确保回测数据与实盘数据时间覆盖一致（因24小时Offset持仓策略需提前1天数据计算）

3. 特殊数据处理

  • 传统金融币：回测需开启「拉黑传统金融币」开关（block_traditional_finance=True），实盘默认拉黑
  • Delist下架币：实盘自动拉黑，回测需手动将data/delist.json中的币种添加到黑名单

回测与实盘数据生成步骤

点击展开詳情

1. 回测数据生成

  • 参数设置：开启「拉黑传统金融币」+ 设置回看天数（建议7天，Lookback_Days=7），保存选币结果CSV
  • 分钟偏移配置：代码版设置Hour_Offset参数，更新预处理数据与第三方数据路径
  • 运行回测：导入策略后运行main.py，选币结果CSV保存在子策略回测结果目录下

2. 实盘数据生成

  • 参数设置：实盘网页版设置回看天数（7天），代码版在框架Config中配置Lookback参数
  • 数据打包：最新实盘框架每小时生成ZIP包，存储在data/Real_time_data目录，仅实盘交易有效（模拟盘不可用）
  • 数据下载：用Termius/FTP工具下载ZIP包，保存到回测框架data/选币对比目录

3. 关键注意事项

实盘数据ZIP包仅占14-几十兆，对比完成后可手动删除旧数据；避免长期开启回看功能，占用存储

网页版工具对比操作全流程

  1. 工具部署：下载对比脚本，放入回测框架tools目录
  2. 参数配置：启动回测网页版，进入「对比分析」模块，选择要对比的回测策略与实盘ZIP包
  3. 生成结果：点击「生成对比数据」，自动解压ZIP包并完成5大维度对比
  4. 结果查看：
    • 总览：查看对比评分（90+分为优）、雷达图与资金曲线差异
    • 细节：币种池对比（排查传统币/Delist币差异）、选币对比（定位差异时间点）、因子值对比（筛选差异因子）
    • 子策略：单独查看多头/空头组合的仓位比例与资金曲线

代码版工具使用（备选方案）

回测与实盘差异核心原因分析

点击展开詳情

1. 数据层面差异

  • 时间差：回测数据比实盘晚6-8小时，24小时Offset策略需提前1天数据，导致回测最后1天空仓
  • 数据源：回测用网页版下载数据，实盘用实时数据，分钟偏移数据需手动同步

2. 配置层面差异

  • 拉黑规则：实盘自动拉黑传统金融币/Delist下架币，回测需手动开启开关/添加黑名单
  • 参数不一致：Mini K线设置、K线获取数量、分钟偏移、仓位比例等Config参数不统一
  • 因子代码：因子名称一致但代码内容不同，导致因子值计算差异

3. 交易层面差异

  • 滑点影响：实盘非整点下单（延迟2-3分钟），选币数量越少滑点影响越大
  • 手续费：实盘账户手续费设置与回测默认值不同

船队作业一完成要点

  • 作业要求：用对比工具分析实盘与回测差异，截图关键对比结果，推测差异原因
  • 关键步骤： 1. 实盘跑策略≥3天，下载ZIP包； 2. 回测配置与实盘一致（拉黑规则/参数/因子）； 3. 生成对比结果，重点截图资金曲线与选币差异； 4. 结合工具分析，指出差异核心原因（如Delist拉黑/数据时差）
  • 加分项：提出差异解决方案（如手动同步Delist黑名单、统一参数配置）

工具使用常见问题与解决方案

🔍 底層邏輯與框架

点击展开詳情

1. 核心思维模型：闭环验证与差异定位

量化策略有效性需通过「回测→实盘→对比→优化」闭环验证，工具的核心价值是将抽象的差异（选币/因子/资金曲线）可视化、可量化，快速定位问题根源，避免盲目优化策略

2. 因果递進关系

环境未升级→数据无法生成→对比工具不可用；数据未对齐→差异误判→策略优化方向错误；配置不一致→回测实盘结果偏差→策略有效性存疑。核心解决路径：先统一环境与配置，再确保数据对齐，最后通过工具定位差异

3. 关键隐喻与案例

「黑名单同步隐喻」：实盘如同实时风控的交易员，自动拉黑下架币/传统金融币，回测如同静态模拟，需手动同步风控规则才能保持一致；案例：某策略回测评分83分，手动添加Delist黑名单并开启传统币拉黑后，评分提升至92分，差异大幅缩小

4. 工具设计底层逻辑

以「用户作业需求」为核心，简化操作流程（网页版可视化），覆盖全维度差异（5大对比维度），同时兼容代码版魔改需求，既满足新手快速完成作业，也支持进阶用户自主拓展功能，平衡易用性与灵活性

✅ 實作步驟 Checklist

  1. 步骤1：环境升级与工具部署

    1.1 升级核心组件：回测框架（≥1.4.3）、实盘框架（≥1.4.4）、数据中心（≥1.1.11）、网页版（回测≥0.1.7，实盘≥0.5.2）；1.2 下载对比脚本，放入回测框架tools目录；1.3 在回测框架data目录下创建「选币对比」文件夹，用于存放实盘ZIP包。

    卡關點：确保所有组件版本达标，否则无法生成选币CSV或实盘ZIP包
  2. 步骤2：实盘数据生成与下载

    2.1 实盘配置：网页版设置回看天数=7，代码版在Config中配置Lookback=7；2.2 运行实盘≥3天（确保数据覆盖）；2.3 用Termius/FTP工具下载实盘ZIP包（路径：data/Real_time_data），保存到回测框架data/选币对比目录。

    卡關點：仅实盘交易有效，模拟盘无法生成数据；ZIP包保留3天，需及时下载
  3. 步骤3：回测数据生成

    3.1 导入策略：官方策略下载沧浪亭26年V2版，自定义策略从实盘account复制Config；3.2 回测配置：开启「拉黑传统金融币」（block_traditional_finance=True），设置Lookback_Days=7，分钟偏移策略需配置Hour_Offset与数据路径；3.3 运行回测，生成选币结果CSV（子策略回测结果目录下）。

  4. 步骤4：网页版对比操作

    4.1 启动回测网页版，进入「对比分析」模块；4.2 选择对比策略（已运行的回测策略）与实盘ZIP包（data/选币对比目录下）；4.3 点击「生成对比数据」，等待结果生成；4.4 分析结果：查看总评分、资金曲线、币种池、选币结果、因子值差异，定位问题。

  5. 步骤5：差异处理与作业完成

    5.1 差异处理：针对Delist币差异，手动添加到回测黑名单；针对参数差异，统一回测与实盘Config配置；5.2 重新生成对比，验证差异是否缩小；5.3 截图关键对比结果（资金曲线、币种池、选币差异），撰写作业报告，推测差异原因与解决方案。

  6. 步骤6：代码版备选操作（可选）

    6.1 解压实盘ZIP包到data/选币对比/[策略名]目录（策略名与回测一致）；6.2 在对比脚本中设置backtest_name参数；6.3 运行脚本，生成HTML结果文件；6.4 打开HTML文件查看对比结果，流程与网页版一致。
