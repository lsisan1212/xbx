实盘前置准备：环境与基础配置

点击展开详情

1. 核心前提：交易所与账户准备

必须完成：注册邮箱→客户端安装→实名认证→验证器安装→入金→子账户开通→统一账户模式切换（可选），具体流程参考学习手册“新手准备-交易开户”栏目。

2. 工具与资源下载

  • 网页版脚本：0.5.1版本压缩包（含Deploy Chronos.sh文件），帖子链接内最底部下载；
  • 策略文件：四龙戏狗策略压缩包（“落单狗”相关配置）；
  • 终端工具：推荐Termius（支持SSH/FTP连接，官网下载），也可使用其他SSH工具。

3. 服务器要求与购买

  • 配置：海外云服务器（推荐腾讯云东京节点，两核4G，年付199元），支持Unix/Linux系统（不推荐Windows）；
  • 原因：境内服务器无法访问境外交易所，个人电脑易断电/中毒，稳定性差；
  • 购买路径：参考帖子52271，腾讯云热门场景→海外服务器→选择东京节点，新用户可续费率，共两年使用期。

网页版部署全流程：从脚本执行到端口配置

点击展开详情

1. 脚本上传与执行

  1. 文件传输：通过FTP将Deploy Chronos.sh脚本上传至服务器对应目录（选币框架→选币目录，仓位管理→仓位管理目录）；
  2. 授权执行：执行chmod +x Deploy Chronos.sh授权，再执行sudo ./Deploy Chronos.sh启动安装；
  3. 关键配置：安装过程中会提示是否安装虚拟内存（推荐4G，输入Y确认），建议将debug模式改为false（避免代码修改后自动刷新）。

2. 端口开通（必做步骤）

服务器防火墙配置：腾讯云服务器→防火墙→添加规则→自定义端口25706（网页版默认端口），否则无法通过浏览器访问。

3. 安装完成验证

安装成功后会生成访问链接，需保存该链接；Docker会自动安装Anaconda、Python环境及三方库，无需手动配置；支持重复执行脚本升级（数据不会丢失，仅更新环境）。

网页版核心操作：登录与数据中心配置

点击展开详情

1. 登录流程

  1. 浏览器访问：粘贴服务器访问链接+端口25706，回车进入登录页；
  2. 验证激活：输入GitHub代码地址中的识别码，完成开源软件授权；
  3. 双重验证：用手机验证器（如谷歌验证器）扫描二维码，输入动态密码；
  4. 微信绑定：扫描二维码登录微信账号，连接彩虹服务。

2. 数据中心初始化

  • 关键参数：设置K线数量（默认2000根）、微信机器人链接（必填，用于信息推送）、分钟偏移（如0/15/55，可设置多个，最多12个）；
  • 数据下载：选择彩虹数据服务（否则无市值数据），启动后自动下载合约与现货数据，约15分钟完成，日志中显示“下载完成”或出现时间线即表示就绪；
  • 分钟偏移：需与实盘框架偏移一致，否则无法获取对应数据。

3. 框架下载与选择

新增框架时选择1.4.0版本（仅该版本支持四龙戏狗策略），网页版会自动下载管理数据中心与框架代码，无需手动上传。

账户配置：普通/统一账户切换与资金转移

点击展开详情

1. 账户类型区别

  • 普通账户：现货与合约账户分离，资金需分别转入，不支持共用保证金；
  • 统一账户：现货与合约共用全仓杠杆账户保证金，降低爆仓风险，无资产门槛（最低300U可开通）。

2. 统一账户开通流程

  1. 普通账户转统一账户：进入币安子账户管理→合约账户→点击右上角三个点→选择“统一账户”切换；
  2. API重建：删除原普通账户API，重新创建统一账户API（需勾选现货交易、杠杆交易、允许杠杆借货、开通统一账户四项权限）；
  3. IP绑定：填写服务器IP地址，仅允许该IP访问API，提升安全性。

3. 资金转移规则

  • 普通账户：资金可转入现货账户或合约账户；
  • 统一账户：资金必须转入“杠杆全仓账户”（否则框架无法识别），现货与合约共用该账户保证金；
  • 转错处理：若转至现货账户，需先转回母账户，再重新转入全仓杠杆账户。

策略部署与实盘操作：调试→模拟→交易

点击展开详情

1. 策略导入与配置

  • 快速导入：通过“导入框架数据压缩包”功能，直接迁移其他服务器的账户配置、因子文件、资金曲线（最便捷，分钟级完成）；
  • 手动配置：新增账户→选择账户类型（普通/统一）→设置分钟偏移→导入因子文件→配置API key→设置保证金（USDT为主，可搭配USDC，比例建议USDT占70%以上，因现货仅支持USDT购买）。

2. 三种运行模式

  1. 实盘调试：仅测试选币流程，不实际交易，用于验证配置（因子文件、参数）是否正确，启动后日志显示选币过程无报错即成功；
  2. 模拟实盘：满仓模拟交易，默认1万U初始资金，无实际盈亏，用于观察策略表现（如四龙戏狗回撤情况）；
  3. 实盘交易：启动后下一个小时开始实际下单，需确保账户有足够资金（USDT在全仓杠杆账户）。

3. 关键操作技巧

  • 清仓：设置账户杠杆为0，保存后下个小时自动清仓；
  • 加仓/减仓：资金曲线中会显示加号（加仓）、红叉（减仓），支持中途转入/转出部分资金（建议在非偏移时间操作）；
  • 多账户运行：一个服务器理论可跑12个子账户（每个分钟偏移一个），但建议仅跑1个，保证稳定性。

常见问题答疑（高频坑规避）

点击展开详情

1. 技术类问题

  • 网页版访问慢：服务器在境外，可尝试使用代理加速；
  • 数据下载失败：检查彩虹数据服务是否勾选，重启数据中心后重新下载；
  • 脚本重复执行：支持重复执行升级，数据不会丢失，仅更新环境；
  • 多框架共存：同一服务器可跑多个不同版本框架，但不建议（影响稳定性）。

2. 账户与资金类问题

  • API加密：支持加密，新手暂不推荐，后续将详细讲解；
  • 资金曲线乱掉：多因资金转错账户，可参考相关帖子修改资金曲线文件后重新上传；
  • 母账户交易：不建议，后续多策略运行时难以统计盈利，建议每个策略对应一个子账户；
  • 统一账户资金看不到：确认资金转入“杠杆全仓账户”，而非现货账户。

3. 策略类问题

  • 四龙戏狗不显示BNB：检查是否误将BNB设为现货（框架不支持BNB现货），或黑名单中包含BNB；
  • 分钟偏移不一致：数据中心与实盘框架的分钟偏移必须一致，否则无法获取数据；
  • 策略暂停后不平仓：暂停策略不会自动平仓，需手动设置杠杆为0。

机器人推送与数据解读

点击展开详情

推送内容包含三大核心信息：

  1. 资金曲线：展示策略盈利/回撤情况，加仓显示加号，减仓显示红叉；
  2. 仓位信息：多头/空头仓位占比，明确当前持仓结构；
  3. 选币详情：多头/空头选中的币种、持仓金额、平均成交价、当前价格、盈亏状态。

解读要点：红色表示亏损，绿色表示盈利，可快速判断单币种及整体策略表现。

🔍 底层逻辑与框架

点击展开详情

1. 核心思维模型

• 简化部署模型：网页版整合Docker环境，自动安装依赖，降低新手技术门槛，无需手动配置Python、Anaconda等；

• 风险隔离模型：子账户与母账户分离，不同策略对应不同子账户，便于盈利统计与风险控制；

• 渐进式操作模型：从实盘调试（无交易）→模拟实盘（无实际盈亏）→实盘交易（真实下单），逐步验证配置，规避直接实盘的操作风险。

2. 因果/递进关系

• 服务器境外部署→可访问境外交易所→实盘正常运行（境内服务器无法满足核心需求）；

• 分钟偏移一致→数据中心与框架同步数据→策略正常选币（偏移不一致将导致无数据可用）；

• 统一账户共用保证金→现货作为合约保证金→降低爆仓风险（普通账户无此优势，现货与合约资金分离）。

3. 关键隐喻与案例

• 隐喻1：子账户=衣服的独立口袋，母账户=钱包，不同口袋放不同策略的资金，独立统计、互不干扰；

• 案例1：某用户将统一账户资金转入现货账户，框架无法识别，导致资金曲线异常，需转回全仓杠杆账户恢复；

• 案例2：四龙戏狗策略因BNB设为现货或加入黑名单，导致持仓中无BNB，需调整配置（BNB仅支持合约）。

📋 实作步骤 Checklist

服务器购买与终端配置
  1. 购买腾讯云海外服务器（两核4G，东京节点，年付199元），完成实名认证与服务器初始化；
  2. 下载Termius终端工具，输入服务器IP、用户名、密码，建立SSH/FTP连接；
  3. 记录服务器IP地址，后续用于API绑定与端口配置。
⚠️ 卡关点：务必选择海外服务器，境内服务器无法访问币安等交易所；推荐Unix/Linux系统，Windows系统无部署教程。
网页版脚本部署与端口开通
  1. 下载网页版脚本（Deploy Chronos.sh）与四龙戏狗策略压缩包；
  2. 通过FTP将脚本上传至服务器对应目录，执行chmod +x Deploy Chronos.sh授权；
  3. 执行sudo ./Deploy Chronos.sh启动安装，期间输入Y安装4G虚拟内存，安装完成后保存访问链接；
  4. 在腾讯云防火墙添加规则，开通25706端口。
⚠️ 卡关点：脚本执行过程中确保网络稳定，避免中断；debug模式需改为false，否则影响使用体验。
网页版登录与数据中心配置
  1. 浏览器访问“服务器IP:25706”，输入GitHub识别码完成授权；
  2. 用手机验证器扫描二维码，输入动态密码，再扫描微信二维码绑定账号；
  3. 进入数据中心，设置K线数量（2000根）、微信机器人链接、分钟偏移（如0/55），勾选彩虹数据服务；
  4. 启动数据中心，等待15分钟数据下载完成（日志显示“下载完成”或出现时间线）。
⚠️ 卡关点：微信机器人链接必填，否则无法接收推送；分钟偏移需记录，后续框架配置需一致。
账户配置与策略导入
  1. 新增框架，选择1.4.0版本（支持四龙戏狗）；
  2. 导入策略压缩包（含账户config、因子文件），或手动新增账户：
    • 选择账户类型（普通/统一），设置分钟偏移（与数据中心一致）；
    • 配置API key（统一账户需勾选四项权限，绑定服务器IP）；
    • 设置保证金（USDT占70%以上，可搭配USDC）。
  3. 上传四龙戏狗策略config文件，完成策略配置。
⚠️ 卡关点：统一账户资金必须转入“杠杆全仓账户”，否则框架无法识别；API权限需勾选完整，避免交易失败。
实盘调试→模拟→交易
  1. 实盘调试：启动调试模式，查看日志无报错（选币流程正常），验证配置正确；
  2. 模拟实盘：启动模拟模式，观察资金曲线与推送信息，确认策略运行正常；
  3. 实盘交易：确认账户资金充足，切换至实盘交易模式，启动后下一个小时开始实际下单；
  4. 日常操作：通过机器人推送查看盈亏，清仓需设置杠杆为0，加仓/减仓在非偏移时间操作。
⚠️ 卡关点：切勿直接启动实盘交易，需先通过调试和模拟验证；清仓不设置杠杆为0，仅暂停策略不会自动平仓。

💡 AI 补充建议与提醒

【AI 提醒】服务器与网络优化
建议选择延迟低的海外节点（如东京、新加坡），减少网页版访问卡顿；若访问慢，可使用代理加速，但需注意合规性；服务器需定期备份数据，避免因异常导致策略配置丢失；不要在服务器上安装无关软件，保持环境干净，降低实盘崩溃风险。
【AI 建议】账户与资金安全
API key务必绑定服务器IP，避免泄露后被恶意操作；统一账户切换时，需先清空普通账户仓位、转移资金，再删除旧API创建新API，避免权限冲突；资金转移时建议小额测试，确认转入账户正确后再批量转入，减少转错风险；定期查看机器人推送，及时发现账户异常（如资金曲线突然大幅波动）。
【AI 提醒】策略运行与维护
一个服务器建议仅跑1个策略/子账户，避免多账户同时运行导致资源不足；网页版升级时，直接重新执行脚本即可，数据不会丢失，但需提前暂停实盘；分钟偏移设置后尽量不频繁修改，若需修改，需同步更新数据中心与框架配置；四龙戏狗策略中，BNB仅支持合约，不可设为现货，否则持仓中无BNB。
【AI 建议】新手避坑指南
新手优先使用普通账户体验，熟悉操作后再切换统一账户；模拟实盘运行1-2周，观察策略表现（如四龙戏狗回撤情况）后，再启动实盘交易；资金曲线异常时，优先检查资金是否转错账户、分钟偏移是否一致、API配置是否正确，再排查策略本身问题；遇到疑问先查看学习手册和攻略帖，再咨询林奇或在群内提问，提高问题解决效率。
【AI 提醒】多策略与多账户管理
若需运行多个策略，建议每个策略对应一个子账户，便于统计各策略盈利；不同子账户的分钟偏移必须不同（如一个0分钟，一个15分钟），避免数据冲突；多服务器运行时，可通过网页版的框架数据压缩包快速迁移配置，无需重复设置；定期清理无用的子账户和策略文件，保持服务器整洁，提升运行效率。
