工具整体架构与核心功能

点击展开详情

1. 整体架构

工具分为两大核心框架，独立部署但功能互补：

  • 选币框架：核心功能模块，含交易分析、因子调试、策略比较、参数平原、IC分析等，偏向单因子分析与单笔交易优化；
  • 仓位管理框架：辅助模块，含相关性分析、仓位占比统计，核心聚焦子策略组合与仓位分布分析。

额外说明：传统分析功能集成在选币框架内，暂未开发与实盘对比功能。

2. 核心设计思路

选币框架：以"分析因子→发现优化点→优化策略"为逻辑，支持无回测调整因子参数，提升调试效率；

仓位管理框架：以子策略为核心，简化功能设计，重点解决多策略组合的相关性与仓位分布问题。

选币框架核心功能详解（重点模块）

点击展开详情

1. 交易初步分析（核心痛点解决）

功能目标：回答三个核心问题——哪些时间亏、哪些币亏、亏时K线是什么样。

操作逻辑：

  • 时间筛选：通过资金曲线查看每月收益/回撤，支持区间筛选（如-40%~-30%回撤区间）；
  • 币种筛选：复选筛选区间内亏损的币种，支持排序与偏移调整；
  • K线查看：联动显示亏损币种的K线图，辅助分析亏损场景。

注意事项：Offset建议单次仅跑1个，多Offset可能出现合并问题，影响可视化效果。

2. 因子调试功能（策略优化核心）

功能目标：分析因子值在买入前/后的变化，以及其他因子同期变化，无需重新跑回测。

操作逻辑：

  • 默认因子：自动加载factor列表中第一个因子（如低价因子），显示参数变化曲线；
  • 参数调整：直接修改因子参数（如250→500），点击刷新即可查看变化，无需跑回测；
  • 多因子支持：最多支持2条因子曲线同时显示，避免界面嘈杂（复杂画图建议使用其他免费工具）。

已知问题：部分场景下参数修改后刷新无反应，后续会更新修复。

3. 策略比较功能

功能目标：对比两个策略（如Demo1与Demo2）的选币差异与交易时间差异。

支持模式：

  • 相同买入时间：筛选同一时间买入但不同时间卖出的币种；
  • 完全不同时间：筛选买入/卖出时间均不同的币种；
  • 核心价值：验证过滤条件效果（如前置/后置过滤后是否筛除无效币种）。

注意事项：运行速度较慢，需耐心等待结果。

4. 其他辅助功能

  • 参数平原：支持多时间维度（如24小时）、多因子参数可视化，生成热力图；
  • IC分析：抄自官方工具，支持自定义持续时间，默认仅算1小时，可修改天数；
  • 分域分析：将因子值分为10组（低3组绿色、中4组紫色、高3组橘红色），支持等宽/等频分箱，适配不同因子类型（如成交量用等频，排名类因子用等宽）；
  • 杠杆分析：显示不同杠杆比例（如杠杆0与杠杆1）的收益曲线，辅助判断杠杆效果。

仓位管理框架核心功能

点击展开详情

1. 相关性分析

功能：生成两张核心图表——资金曲线关系图、选币差异百分比图，支持添加多个子策略对比。

使用场景：判断不同子策略的协同性，避免过度集中风险。

2. 仓位占比统计

功能：筛选指定仓位占比区间（如多头占比0.5~0.65），统计该区间在整个策略周期中的出现次数、持续小时数及对应收益，联动显示子策略与主流币种（BTC/ETC）的曲线。

使用场景：分析特定仓位分布下的策略表现，优化仓位配置。

3. 安装与使用说明

安装流程与选币框架一致：复制安装包到对应目录，执行命令即可；

核心特点：功能简洁，操作门槛低，无需复杂配置，重点聚焦仓位核心问题。

关键使用技巧与注意事项

点击展开详情

1. 选币框架使用技巧

  • 因子选择：过滤因子仅显示变化值，调试时建议聚焦1-2个核心因子，避免多因子干扰；
  • 分箱选择：排名类因子（如传统因子）用等宽分箱，非排名类（如成交量）用等频分箱，避免币种过度集中；
  • 周期选择：成交量等因子建议用"当前小时"周期，与同期币种对比更合理；
  • 策略比较：优先对比相同买入时间的差异，快速验证过滤效果。

2. 常见问题与规避方法

  • Offset冲突：单次仅跑1个Offset，避免合并后可视化效果差；
  • 刷新无效：部分因子参数修改后刷新无反应，可重启工具或等待后续版本修复；
  • 功能局限：复杂画图（如3条以上因子曲线）建议使用其他免费工具（如确定余）；
  • 数据兼容性：新币2.0公测版暂未适配，需等待后续测试。

3. 核心功能优先级建议

新手优先掌握：交易初步分析（亏损时间/币种/K线）→ 因子调试（核心因子变化）→ 策略比较（选币差异）；

进阶使用：参数平原→IC分析→分域分析→杠杆分析；

仓位管理：先掌握相关性分析，再使用仓位占比统计，适配多策略组合场景。

🔍 底层逻辑与框架

点击展开详情

1. 核心思维模型

• 痛点驱动模型：工具设计围绕量化策略优化的核心痛点（亏损定位、因子调试、策略对比），优先解决高频需求；

• 分层功能模型：选币框架聚焦"单一策略优化"，仓位管理框架聚焦"多策略组合分析"，分层设计避免功能冗余；

• 效率优先模型：支持无回测调试因子，减少重复跑回测的时间成本，提升策略迭代效率。

2. 因果/递进关系

• 策略优化需求→工具核心功能（亏损分析→因子调试→策略对比）→ 高效迭代策略；

• 单策略优化→多策略组合→ 仓位管理框架（相关性分析→仓位占比统计）→ 控制组合风险；

• 功能简化设计→降低使用门槛→ 新手快速上手→ 聚焦核心需求而非全面覆盖。

3. 关键隐喻与案例

• 隐喻1：选币框架=策略"显微镜"，聚焦单一策略的细节优化（因子、参数、交易时机）；

• 隐喻2：仓位管理框架=策略"望远镜"，聚焦多策略组合的整体风险与仓位分布；

• 案例1：通过交易初步分析，快速定位某策略在2022年3月的亏损币种（如某垃圾币），发现其K线跌破关键支撑位，后续优化过滤条件；

• 案例2：通过分域分析，发现某因子值低的币种在回测中上涨概率更高，调整策略优先选择低因子值标的。

工具下载与安装部署
  1. 访问帖子链接6868333，下载选币框架与仓位管理框架安装包；
  2. 创建对应目录：新建"选币"和"仓位管理"两个文件夹，将对应安装包复制粘贴到目录中；
  3. 执行安装命令：在命令行中输入指定命令，完成工具安装；
  4. 配置debug参数：打开配置文件，将debug模式改为false，避免自动刷新干扰；
  5. 启动验证：执行启动命令（类似Python启动方式），出现指定代码行即安装成功。
⚠️ 卡关点：确保安装包放置目录正确，命令输入无误；若启动失败，检查Python环境与依赖包是否齐全。
选币框架核心功能实操（交易分析+因子调试）
  1. 加载策略：导入Demo1或Demo2策略，选择单个Offset（建议先跑1个）；
  2. 交易初步分析：
    • 查看资金曲线，筛选亏损区间（如-30%~-20%）；
    • 复选筛选该区间内的亏损币种，查看对应的K线图；
    • 记录亏损时间、币种及K线特征。
  3. 因子调试：
    • 默认加载第一个因子（如低价因子），查看参数变化曲线；
    • 修改因子参数（如250→500），点击刷新查看变化（若刷新无效，重启工具）；
    • 对比买入前/后因子值变化，识别优化点。
  4. 策略比较：选择Demo1与Demo2，按"相同买入时间"模式运行，查看选币差异，验证过滤效果。
⚠️ 卡关点：多Offset同时运行可能导致可视化混乱，建议单次仅选1个；因子调试时最多显示2条曲线，避免界面嘈杂。
选币框架进阶功能实操（参数平原+分域分析）
  1. 参数平原：选择目标因子，设置时间维度（如24小时），运行生成热力图，分析参数稳定性；
  2. 分域分析：
    • 选择因子（如成交量），设置分箱方式（等频）；
    • 选择周期（当前小时），运行生成分域图；
    • 观察低/中/高因子值组的收益表现，调整策略选股偏好。
  3. IC分析：设置持续时间（如7天），运行生成IC曲线，评估因子有效性；
  4. 杠杆分析：选择不同杠杆比例（如0和1），对比收益曲线，判断杠杆对策略的影响。
⚠️ 卡关点：分箱方式需根据因子类型选择（排名类→等宽，非排名类→等频）；IC分析运行时间较长，需耐心等待。
仓位管理框架实操
  1. 加载子策略：导入多个子策略（如Demo1的多个子策略）；
  2. 相关性分析：运行生成资金曲线关系图与选币差异百分比图，判断子策略协同性；
  3. 仓位占比统计：
    • 设置仓位区间（如多头占比0.5~0.65）；
    • 运行统计该区间的出现次数、持续小时数及收益；
    • 查看子策略与BTC/ETC的曲线联动，分析仓位分布合理性。
  4. 优化调整：根据分析结果，调整子策略权重或仓位分布，降低组合风险。
⚠️ 卡关点：仓位管理框架功能简洁，重点关注核心数据（出现次数、收益），无需过度纠结细节；若子策略过多，可分批对比。
策略优化落地（基于工具分析结果）
  1. 问题定位：通过交易分析找到策略亏损核心原因（如特定币种、时间区间）；
  2. 因子优化：基于因子调试结果，调整因子参数（如增大/减小阈值）；
  3. 过滤调整：根据策略比较结果，优化前置/后置过滤条件，筛除无效币种；
  4. 组合优化：利用仓位管理框架分析，调整子策略权重与仓位分布；
  5. 回测验证：将优化后的策略进行回测，对比优化前后的收益与回撤。
⚠️ 卡关点：优化后需通过回测验证效果，避免仅凭工具分析直接实盘；工具仅提供分析支持，不替代回测验证。
