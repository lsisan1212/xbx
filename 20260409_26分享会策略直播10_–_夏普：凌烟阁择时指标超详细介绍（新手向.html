趋势类指标（3个）：MA（均线）

点击展开詳情

1. 定义

过去N个周期收盘价的平均值连成的线，被誉为"技术指标之王"，衍生出SMA、EMA、WMA等多种算法，课程聚焦最简单的MA（等权平均）

2. 计算方法

MA(N) = 最近N个周期收盘价之和 / N（需使用复权价格）

示例：MA12 = 过去12小时收盘价平均值，Excel公式：=AVERAGE(E2:E13)

3. 使用规则

  • 开仓：收盘价 > MA（认为价格上涨）
  • 平仓：收盘价 < MA（认为价格下跌）
  • 信号输出：1=开仓，0=空仓

4. 特点

  • 小参数（如MA5）：紧跟行情，但易受异常值影响
  • 大参数（如MA20）：抗干扰能力强，但行情反应滞后
  • 长趋势行情中持仓稳定性好，震荡行情易频繁切换信号

趋势类指标（3个）：海龟择时

点击展开詳情

1. 定义

基于价格突破的趋势追踪策略，源自《海龟交易法则》，核心是追踪最近N个周期的最高价与最低价，判断价格突破方向

2. 计算方法

  • 最高价线：截止到上一根K线的最近N个周期最高价（如24小时）
  • 最低价线：截止到上一根K线的最近M个周期最低价（如48小时）
  • 参数N、M可自定义，无固定标准

3. 使用规则

  • 开仓：当前价格 > 上一根K线的N周期最高价（突破新高，预期上涨）
  • 平仓：当前价格 < 上一根K线的M周期最低价（突破新低，预期下跌）

4. 特点

  • 自带波动管理：波动小时（两条线距离近）交易频繁，波动大时（两条线距离远）交易稀少
  • 参数影响交易频率：小参数交易频繁，大参数交易稀疏
  • 趋势类指标中表现最优，混合参数夏普比率优于MA和布林带

趋势类指标（3个）：布林带

点击展开詳情

1. 定义

基础通道类择时策略，由均线和上下轨构成价格通道，上轨=均线+M倍标准差，下轨=均线-M倍标准差

2. 计算方法

  • 第一步：计算MA（如MA40，最近40周期收盘价平均值）
  • 第二步：计算最近40周期收盘价的标准差（STD）
  • 第三步：上轨=MA40 + M×STD，下轨=MA40 - M×STD（推荐M=0.5-1.3）

3. 使用规则

  • 开仓：价格 > 上轨（突破上轨，预期上涨）
  • 平仓：价格 < 下轨（突破下轨，预期下跌）
  • 空值处理：延续之前的信号（1延续为1，0延续为0）

4. 特点

  • 自带波动适应：波动大时通道变宽，波动小时通道变窄
  • M值决定通道宽度：M越小交易越频繁，M越大交易越稀少
  • 基于正态分布：M=1时，68.2%的价格在通道内；M=2时，95.4%的价格在通道内

反转类指标（3个）：RSV

点击展开詳情

1. 定义

衡量当前价格相对于历史价格的水平，取值范围0-100，越接近0价格越低，越接近100价格越高

2. 计算方法

RSV = （当前收盘价 - 最近N周期最低价） / （最近N周期最高价 - 最近N周期最低价）× 100

注：最高价与最低价均截止到当前K线，且参数N一致（区别于海龟择时）

3. 使用规则

  • 开仓：RSV < 10（价格处于低位，预期反弹）
  • 平仓：RSV > 90（价格处于高位，预期下跌）

4. 特点

  • 适合大参数：小参数表现差，参数≥600后表现稳定，1000以上参数平面基本无变化
  • 纯反转逻辑：仅基于价格高低位判断，无趋势过滤

反转类指标（3个）：KDJ

点击展开詳情

1. 定义

RSV的进阶版本，通过对RSV和K值分别计算均线，加入趋势过滤，形成"反转+趋势"的复合逻辑

2. 计算方法

  • 第一步：按RSV公式计算RSV值（0-100）
  • 第二步：K值 = 最近N周期RSV的平均值（如12周期）
  • 第三步：D值 = 最近N周期K值的平均值（如12周期）

3. 使用规则

  • 开仓：RSV < 10（价格低位）且K上穿D（上涨趋势）
  • 平仓：RSV > 90（价格高位）且K下穿D（下跌趋势）

4. 特点

  • 反转+趋势复合：既捕捉低位反转机会，又通过K/D交叉过滤虚假信号
  • 反转类指标中表现最优：小市值和凯师傅策略中均有出色表现
  • 信号更稳健：相比RSV，减少盲目抄底/逃顶的失误

反转类指标（3个）：CCIQ

点击展开詳情

1. 定义

衡量当前价格偏离度在历史上的分位水平，取值0-1，越接近0偏离度越小，越接近1偏离度越大

2. 计算方法（多步骤）

  • 第一步：计算典型价格TP = （最高价+最低价+收盘价）/ 3
  • 第二步：计算最近M周期TP的平均值（TM）
  • 第三步：计算最近M周期TP与TM的绝对偏离值，再求平均值（TTPMD）
  • 第四步：CCI = （当前TP - TM） / TTPMD × 0.015（0.015为缩放系数，可省略）
  • 第五步：CCIQ = CCI在最近180/250周期的分位值（rank）

3. 使用规则（配合RSV）

  • 开仓：RSV < 10（价格低位）且CCIQ < 0.1（严重低估）
  • 平仓：RSV > 90（价格高位）且CCIQ > 0.9（严重高估）

4. 特点

  • 逻辑复杂：需多步骤计算，核心是"价格低位+严重低估"双重确认
  • 反转+趋势复合：通过偏离度过滤，避免在低位震荡中盲目开仓

论坛优质指标：回撤择时指标

点击展开詳情

1. 定义

基于价格回撤幅度的择时策略，核心是规避快速暴跌风险，对阴跌不敏感，源自团队作业帖（强力苏打水老板）

2. 计算方法

回撤幅度 = （最近N周期最高价 - 当前收盘价） / 最近N周期最高价 × 100%

示例：N=4时，最近4小时最高价9.99，当前收盘价9.46，回撤幅度=（9.99-9.46）/9.99≈5.3%

3. 使用规则

  • 开仓：回撤幅度 < 2%（情绪恢复，风险可控）
  • 平仓：回撤幅度 > 4%（快速暴跌，规避风险）

4. 特点

  • 聚焦暴跌规避：历史数据证明，快速下跌往往引发更大幅度回调，阴跌影响有限
  • 大部分时间持仓：仅在快速暴跌时平仓，不影响正常趋势中的持仓收益
  • 逻辑支撑：底层数据显示，标普500历史上的剧烈下跌多由快速下跌引发

🔍 底層邏輯與框架

点击展开詳情

1. 核心思维模型：趋势追踪与反转捕捉

择时指标本质分为两类：趋势类（追踪已形成的趋势，买在右侧）和反转类（捕捉价格极值后的反转，偏左侧）。趋势类通过均线、价格突破等确认趋势方向，反转类通过价格分位、偏离度等判断极值，两者结合可覆盖不同行情场景。

2. 因果递進关系

新手入门需简单易懂的指标→选择MA、海龟、RSV等基础指标→复杂指标（KDJ/CCIQ）在基础指标上增加过滤条件→工具可视化降低实操门槛→多指标混合覆盖降低单一指标风险→团队任务强化实操与魔改能力，形成"入门-进阶-实战"的完整路径。

3. 关键隐喻与案例

「海龟交易隐喻」：普通人通过固定规则可成为优秀交易者，如同海龟可被批量培养，证明量化规则的有效性；案例：海龟指标在趋势行情中仅需1-2次交易即可捕捉大部分涨幅，波动大时自动减少交易，避免盲目操作。

4. 指标选择底层逻辑

指标选择需匹配行情特征：趋势明确时用MA/海龟/布林带，震荡行情中反转类指标更优；参数选择需平衡灵敏度与稳定性：小参数适合震荡，大参数适合趋势；核心原则是"简单有效"，复杂指标不一定优于基础指标（如MA虽简单，但仍是核心基础）。

✅ 實作步驟 Checklist

  1. 步骤1：基础工具准备与数据获取

    1.1 安装Excel（计算验证）、Python环境（可选，运行可视化工具）、彩虹客户端（回测）；1.2 获取股票/币圈小时级数据（含时间、开盘价、收盘价、最高价、最低价），确保数据已复权；1.3 下载直播配套Excel表格和可视化工具代码（直播后发放）。

    卡關點：数据需复权，否则计算结果会失真；可视化工具需配置数据路径，纯前端代码无需额外画图库
  2. 步骤2：单个指标计算与验证（Excel实操）

    2.1 趋势类指标：按公式计算MA（如MA12）、海龟最高价/最低价、布林带上下轨，对比Excel自带函数结果；2.2 反转类指标：计算RSV、KDJ（K/D值）、CCIQ（多步骤），验证取值范围（0-100或0-1）；2.3 回撤指标：计算最近N周期最高价与回撤幅度，确认平仓/开仓条件触发逻辑。

  3. 步骤3：指标信号生成与可视化

    3.1 在Excel中编写信号公式（如MA：=IF(收盘价>MA12,1,0)），生成0/1信号列；3.2 配置可视化工具：输入数据路径、股票代码、时间范围，定义指标计算逻辑和信号规则；3.3 运行工具，查看K线、指标曲线与信号点（红点/绿点），验证信号与行情的匹配度。

  4. 步骤4：多指标混合与回测

    4.1 趋势类混合：选择MA（小参数）+ 海龟（中参数）+ 布林带（大参数），按等权或优化权重组合；4.2 反转类混合：选择KDJ + CCIQ，叠加RSV过滤条件；4.3 在彩虹客户端导入混合策略，回测小市值/凯师傅等选股策略，对比单一指标与混合指标的夏普比率、最大回撤。

    卡關點：混合时需注意指标风格互补，避免同类指标过度叠加（如MA与布林带均属趋势类，权重需合理分配）
  5. 步骤5：团队任务参与与指标魔改

    5.1 选择凌烟阁旗舰船队或选股团队，查看对应任务要求；5.2 完成基础任务（如回测与实盘对比、指定指标实现），发布帖子获取保证金退还资格；5.3 进阶任务：参考回撤指标思路，魔改现有指标（如给KDJ增加回撤过滤），提升策略稳定性。
