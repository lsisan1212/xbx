政策背景与事件定义

点击展开詳情

1. 核心政策

2024年10月17日，央行、金融监管总局、证监会联合发布《关于设立股票回购增持再贷款有关事宜的通知》，支持金融机构为上市公司及主要股东提供贷款，专项用于股票回购与增持，推动市值管理。

2. 政策核心特点

  • 基本面要求：需符合股份回购规则
  • 专款专用：封闭运行，仅用于回购/增持
  • 低利率：原则上不超过2.25%
  • 政策豁免：豁免信贷资金流入股市的限制

3. 事件定义与影响

事件：上市公司发布"贷款回购/增持"相关公告；核心影响：回购减少流通股数→EPS提升，低利率降低成本→股东收益增厚，市场对政策红利反应积极。

4. 公告关键信息

核心要素：贷款金额、回购价格上限、回购数量/比例，其中回购价格上限对股价影响显著（如盛和资源公告回购价≤30元，股价接近后暴跌8%）。

事件研究法核心框架

点击展开詳情

1. 核心概念定义

  • 异常收益率（AR）：个股实际收益率 - 预期收益率（预期收益率通过市场模型估算）
  • 平均异常收益率（AAR）：多个标的AR的平均值
  • 累计异常收益率（CAR）：特定时间段内每日AR的累加值，衡量事件长期影响

2. 预期收益率估算（市场模型法）

  1. 估算窗口：事件日前250个交易日至前30个交易日
  2. 市场基准：沪深300指数收益率（R_M）
  3. 线性回归：通过个股收益率（R_I）与R_M回归，得到阿尔法（超额收益）和贝塔（市场敏感度），公式：R_I = α + β×R_M + ε（ε为扰动项）
  4. 预期收益计算：基于回归得到的α和β，结合实时R_M计算E(R_I)

3. 事件窗口分析

  • 短期窗口（T-10至T+10）：T-1至T+1有显著正超额（可能存在信息泄露），T+2出现负向回调（短期获利了结），中长期仍有正超额
  • 长期窗口（1月/2月/3月）：持有时间越长，累计异常收益越高，胜率、盈亏比、预期收益均随持有期提升
  • 核心结论：事件适合中长期策略，放弃短期信息泄露红利（普通投资者无法把握）

策略构建与优化过程

点击展开詳情

1. 基础策略（机械策略）

  • 规则：月持仓，检测前一个月所有贷款回购公告，等额买入对应个股
  • 表现：年化收益40%，2025年3月后开始跑赢中证1000/沪深300

2. 持仓周期优化

测试不同持仓周期后，确定最优参数：2W（两周持仓）+ Offset 0/1，卡玛值达3.9，年化收益47.51%，显著优于月持仓。

3. CAR3因子筛选优化

  • 因子定义：CAR3 = T-1至T+1期间的累计异常收益率（衡量市场对事件的短期反应强度）
  • 筛选规则：按CAR3分桶，仅买入头部分桶（市场反应最强）的个股
  • 优化效果：年化收益飙升至200%+，卡玛值达20，无未来函数，策略表现炸裂

4. 策略核心逻辑

强者恒强：短期市场反应强烈的贷款回购个股，中长期超额收益更显著；通过CAR3因子筛选，剥离市场反应弱的标的，提升策略有效性。

实盘经验与心态管理

点击展开詳情

1. 实盘时间线与表现

  • 启动阶段（2025年10-11月）：初期有小幅盈利，随后进入漫长回撤
  • 回撤阶段（2025年11月-2026年1月）：持续横盘/下跌，同期大盘表现差，策略无选股（公告减少）
  • 反弹阶段（2026年2-4月）：策略触发买入信号（如金开新能、眼眶能源、新朋股份），但因心态问题未执行，错失收益

2. 核心实盘教训

  1. 策略信仰缺失：纯程序员背景，对财务/市场逻辑理解不足，回撤期怀疑策略有效性
  2. 心态管理失效：长期回撤导致信心崩溃，错过反弹阶段的买入信号
  3. 执行一致性不足：边旅游边实盘，网络不稳定，策略运行断断续续
  4. 选股数量衰减：2026年后公告极少，策略无足够标的可买，影响实盘落地

3. 实盘执行建议

  • 操作频率：每周抽固定时间运行策略，手工买入（事件频率低，无需自动交易）
  • 资金分配：选股数量少，采用等额分配仓位
  • 心态建设：理解策略底层逻辑，回撤期坚定持有，避免因情绪放弃信号

策略风险与限制

点击展开詳情

1. 核心风险提示

  • 回测时间短：策略基于2024年10月后数据，未穿越完整牛熊周期，行情适配性存疑
  • 公告数量衰减：2025年8月后事件急剧减少，策略容量小，资金量大的投资者无法参与
  • 政策风险：贷款回购政策可能取消或调整，导致事件消失
  • 个股风险：部分标的可能存在回购不及预期、业绩暴雷等问题，影响组合表现

2. 失败案例参考

对预增、定增等公告的事件研究效果极差，仅贷款回购公告具备显著超额收益，说明事件驱动策略需精准选择事件类型。

3. 策略适用场景

适合小资金参与（单策略资金量建议≤50万），作为量化组合的补充策略，而非核心策略；市场低位时公告数量较多，策略效果更优。

🔍 底層邏輯與框架

点击展开詳情

1. 核心思维模型：政策红利+事件驱动+强者恒强

贷款回购策略的本质是捕捉政策红利带来的市场情绪溢价与基本面改善：政策支持降低上市公司回购成本（低利率），回购行为直接提升EPS（减少流通股），形成双重利好；叠加"强者恒强"逻辑（短期市场反应强烈的标的中长期表现更优），通过CAR3因子筛选强化信号，提升策略胜率与收益。

2. 因果递進关系

政策出台→上市公司发布贷款回购公告→市场情绪反应（短期上涨）→基本面改善（长期EPS提升）→超额收益产生；策略层面：事件筛选（贷款回购）→预期收益估算（市场模型）→异常收益计算（AR/CAR）→因子筛选（CAR3）→持仓优化（2W周期）→实盘落地，每一步均为前一步的强化，最终实现收益放大。

3. 关键隐喻与案例

「政策红包隐喻」：贷款回购政策如同监管发放的"投资红包"，上市公司通过低息贷款回购股票，股东间接受益；案例：新朋股份公告后策略触发买入信号，若坚定执行可获得显著收益，而因心态问题错失机会，印证了"策略落地比回测更重要"。

4. 事件研究法底层逻辑

事件研究法的核心是剥离市场整体波动的影响，精准衡量特定事件对个股的独立冲击。通过构建估算窗口（分离正常收益）与事件窗口（捕捉异常收益），利用统计学方法（线性回归）量化事件影响，该框架可复用至业绩预告、并购重组、政策出台等各类事件分析，具备极强的通用性。

✅ 實作步驟 Checklist

  1. 步骤1：数据获取与预处理

    1.1 选择数据来源：万德（付费，数据全）或聚潮资讯（免费，需爬虫）；1.2 编写爬虫代码：爬取"贷款回购/增持"相关公告，提取股票代码、公告日期（核心字段），可选行业、回购价格等扩展字段；1.3 数据清洗：剔除重复公告、无效公告（如未明确贷款用途的公告），按公告日期排序。

    卡關點：聚潮资讯爬虫需模拟浏览器请求，避免被封IP；彩虹框架公告数据覆盖不全，不建议直接使用
  2. 步骤2：事件研究法实现（Python）

    2.1 计算预期收益率：选择沪深300作为基准，构建市场模型，通过线性回归得到个股α和β；2.2 计算异常收益率（AR）：AR = 个股实际收益率 - 预期收益率；2.3 计算累计异常收益率（CAR）：按事件日对齐（T0为公告日），计算T-1至T+1的CAR3；2.4 分桶分析：按CAR3分桶，验证头部分桶的超额收益显著性。

  3. 步骤3：策略参数优化

    3.1 持仓周期测试：测试1W、2W、月持仓等周期，确定最优周期为2W；3.2 Offset优化：测试Offset 0-3，确定最优为0和1；3.3 筛选条件设置：仅保留CAR3头部分桶个股（如前20%）；3.4 回测验证：回测2024年10月至今数据，验证年化收益、最大回撤、卡玛值等指标。

  4. 步骤4：彩虹框架适配

    4.1 因子编写：将CAR3因子、公告日期筛选逻辑写入彩虹框架；4.2 策略配置：设置持仓周期2W、Offset 0/1、选股数量（填20，因实际数量少）、资金等额分配；4.3 回测对比：对比彩虹数据与自建数据的回测效果，若差异较大，优先使用自建数据。

    卡關點：彩虹数据公告覆盖不全，需手动补充关键公告，避免策略失效
  5. 步骤5：实盘部署与监控

    5.1 资金准备：单策略资金建议≤50万，避免选股数量少导致的集中度风险；5.2 执行频率：每周固定时间运行策略，手工买入筛选后的个股；5.3 持仓管理：按2W周期持有，到期自动卖出，无需额外止盈止损；5.4 动态监控：跟踪公告数量变化，若连续多周无事件，暂停策略。

  6. 步骤6：风险控制与优化

    6.1 分散持仓：若选股数量≥2，等额分配资金，降低个股风险；6.2 行情适配：市场高位时减少资金投入，低位时加大配置；6.3 策略迭代：若公告数量持续衰减，可尝试加入行业筛选、回购比例筛选等优化条件。
