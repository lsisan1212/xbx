重點摘要與邏輯軸

[00:00-10:00]客户端核心认知与实盘准备

客户端是整合数据处理、策略选股、交易下单的工具箱，实盘前需完成数据更新、策略导入、选股与QMT启动四大核心准备。

點擊展開詳情

1. 客户端核心模块：数据中心（历史+实时数据）、策略中心（选股策略管理）、实盘中心（交易下单），对应三大内核，按工作流执行；

2. 实盘前四大准备：①数据更新（7类基础数据，晚8点后+早8点前更新，公告标题汇总7:30更新）；②策略导入（收盘后导入，设置资金分配，回测跑通）；③8点前选股（启动自动实盘生成交易计划）；④9点前启动QMT（检查日志无报错，下单模块绿色运行）；

3. 数据订阅：需订阅历史指数、指数小时、股票小时、全息数据、公告标题汇总、5分钟收盘价、财务数据7类基础数据。

[10:00-25:00]客户端与QMT安装配置

客户端需安装最新版本并完成登录与路径设置，QMT需咨询客户经理确认版本，配置账号与路径后即可对接交易。

點擊展開詳情

1. 客户端安装：下载3.6.4版本（国内推荐百度云），默认安装后微信扫码登录，设置SSD硬盘数据路径，检查内核为最新稳定版；

2. QMT安装：从腾讯微云下载，咨询客户经理是否需升级，安装后选择独立交易，无需额外安装Python包；

3. 实盘参数设置：输入QMT账号与user data mini目录路径，新增功能可设置（模糊信号禁用、开盘涨停卖出启用、清除因子缓存）；

4. 注意事项：实盘参数需收盘后设置，开盘时禁止修改，清除因子缓存可解决选股异常问题。

[25:00-40:00]实盘交易流程与可视化监控

交易时段按时间节点执行，通过客户端可视化界面监控交易状态，最终需在QMT确认下单结果。

點擊展開詳情

1. 关键时间节点：9:15-20集合竞价卖出（启用涨停卖出则挂单）；9:30-35开盘换仓（凌烟阁策略）；9:55定风波策略换仓；盘中每5分钟拉取实时数据；

2. 可视化监控：实盘中心可查看交易状态（集合竞价挂单、生成交易计划、实盘买入/卖出）、个股仓位变化，实时数据中心可查看数据拉取进度（成功数量、失败原因）；

3. 交易确认：客户端显示交易完成后，需在QMT确认下单结果，确保交易执行成功；

4. 实时数据来源：从QMT拉取，供凌烟阁个股择时与定风波策略使用，9:45前需拉齐数据。

[40:00-55:00]策略导入与管理

策略从精心随机下载，支持选股策略库与综合策略库导入，核心可编辑资金分配与换仓时间，删除策略需先清仓。

點擊展開詳情

1. 策略来源：下载官方精心随机策略包，建议先通过回测框架跑通、参数遍历优化后再导入客户端；

2. 策略库差异：①选股策略库：仅导入选股策略，导入方式为覆盖替代；②综合策略库：支持选股+仓管策略，导入方式为添加删除，灵活度更高，功能全覆盖，推荐新手使用；

3. 可编辑项：①资金分配比例（按策略组设置，总和为1）；②换仓时间（可重新生成随机卖出/买入时间，同类型换仓有嘎叉机制）；③选股数量（不建议修改）；

4. 策略删除：不可直接删除持仓策略，需先将资金比例设为0，待所有持仓股票卖出后再删除。

[55:00-75:00]任务一作业：回测实盘对比

任务一核心是对比回测与实盘的选股结果和资金曲线，需使用选股选币对比统一版工具，可通过调整参数制造差异完成作业。

點擊展開詳情

1. 工具下载：从邢大直播下方下载「选股选币对比统一版」脚本，放入回测框架根目录；

2. 数据准备：①实盘数据：实盘中心→打开策略结果文件夹，复制选股结果与data目录下的运行缓存，放入data/选股对比/实盘目录；②回测数据：回测框架跑相同策略，复制选股结果与运行缓存，放入data/选股对比/回测目录；

3. 对比执行：设置工具模式为Stock，配置回测与实盘路径，运行工具生成差异报告；

4. 作业撰写：①策略介绍（选股+择时逻辑）；②实盘/回测环境（版本、模拟资金）；③差异截图与说明（如过滤板块不同导致选股差异）；④资金曲线对比（同花顺实盘曲线+回测曲线）；

5. 差异制造：可调整回测框架过滤板块（如仅选主板）、模拟资金，或删除部分回测选股结果，确保生成差异报告。

[75:00-90:00]常见问题与关键注意事项

汇总实盘过程中高频问题，明确操作规范与避坑要点，确保交易顺利执行。

點擊展開詳情

1. 数据相关：历史数据每周仅能全量下载一次，故障导致下载失败可联系林奇重置；实时数据仅交易时段有，非交易时段手动执行可测试下载是否正常；

2. 交易相关：仓位变化需等下次换仓生效；入金后资金需下次换仓时按比例分配；手动加仓会脱离策略，建议单独开账户；凌烟阁个股择时成交可视化暂未完善，可通过日志+QMT确认；

3. 策略相关：删除无持仓策略不影响正在运行的策略；同一策略组内策略换仓时间随机生成，避免集中交易；

4. 其他：逆回购资金不占用买股票额度但无法提现；周五也会执行逆回购；ST股票选股需确认策略选股范围。

[90:00-100:00]学习建议与反馈渠道

新手建议用小资金实践，通过真金白银交易积累经验，问题可通过群聊或攻略帖留言反馈。

點擊展開詳情

1. 学习建议：新手先用小资金熟悉实盘流程，参与实盘活动积累经验，避免纯模拟交易（缺乏盈亏体感）；

2. 反馈渠道：客户端使用问题可在群内提问，或在实盘客户端攻略帖、回测实盘对比攻略帖下留言，高关注度问题会优先解决；

3. 后续更新：研究中心6月底前上线，凌烟阁个股择时成交可视化功能持续优化。

底層邏輯與框架

點擊展開詳情

1. 核心思維模型：「流程化+可视化」实盘闭环

客户端设计核心是将复杂的实盘交易拆解为「准备-执行-监控-验证」四大流程，通过模块化分工（数据-策略-交易）降低新手门槛，同时提供可视化界面让交易状态可查、可追溯。核心逻辑是「工具替代手动」，从数据处理到下单全流程自动化，仅需新手完成前期配置与后期监控。

2. 因果關係鏈

  • 因：新手实盘面临流程复杂、参数混乱、交易无反馈等问题，容易出错；
  • 果：通过分模块设计、明确时间节点、可视化监控，让新手按步骤执行，降低操作难度；
  • 递進關係：安装配置（基础准备）→ 数据更新（数据基础）→ 策略导入（核心逻辑）→ 实盘交易（执行环节）→ 作业对比（验证环节），每一步都为下一步提供支撑，形成完整闭环。

3. 關鍵隱喻與案例

• 隱喻：将客户端比作「实盘工具箱」，三大内核是工具箱内的核心工具，按工作流顺序调用，无需新手关注底层逻辑；策略库比作「策略文件夹」，综合策略库支持灵活增删，如同整理文件般便捷；

• 案例：凌烟阁小市值策略实盘演示中，8点前启动自动实盘选股，9:15集合竞价挂单卖出，9:30开盘换仓买入，通过客户端可视化界面实时监控每一步状态，最终在QMT确认成交，完整呈现实盘闭环；任务一作业中，通过调整回测框架过滤板块制造差异，生成报告完成作业，解决新手无差异可写的问题。

實作步驟 Checklist

  • 步驟1：客户端安裝與登錄

    工具：浏览器、百度云；参数：客户端3.6.4版本；操作：下载安装→微信扫码登录→设置SSD数据路径→检查内核为最新稳定版；卡关点：登录需绑定彩虹官网权限，数据路径需选择空间充足的SSD

  • 步驟2：QMT安裝與配置

    工具：腾讯微云、券商客户经理；操作：下载QMT→咨询客户经理确认版本→安装后选择独立交易→客户端实盘参数中输入QMT账号与路径；卡关点：QMT路径需准确找到user data mini目录，账号需咨询客户经理获取

  • 步驟3：數據訂閱與更新

    工具：客户端数据中心；操作：订阅7类基础数据→首次手动全量下载（一个一个点击）→设置定时更新（晚8点后+早8点前）；卡关点：全量下载失败需联系林奇重置次数，公告标题汇总需7:30后更新

  • 步驟4：策略導入與設置

    工具：精心随机策略包、回测框架；操作：下载策略包→回测框架跑通优化→客户端添加策略（综合策略库推荐）→设置资金分配比例→重新生成换仓时间；卡关点：策略需与回测框架参数一致，资金比例总和为1

  • 步驟5：實盤前準備與啟動

    工具：客户端、QMT；操作：早8点前启动自动实盘→查看选股结果→9点前启动QMT→检查日志无报错→确认下单模块绿色运行；卡关点：选股结果异常可清除因子缓存，QMT连不上需检查路径与账号

  • 步驟6：實盤交易與監控

    工具：客户端实盘中心；操作：9:15关注集合竞价挂单→9:30监控开盘换仓→盘中查看实时数据拉取进度→QMT确认成交结果；卡关点：凌烟阁成交可视化暂不完善，需结合日志与QMT确认

  • 步驟7：任務一作業數據準備

    工具：选股选币对比统一版脚本；操作：下载脚本放入回测框架→复制实盘选股结果与运行缓存→回测框架跑相同策略→复制回测数据到对应目录；卡关点：实盘与回测策略参数需完全一致，否则差异无意义

  • 步驟8：執行對比與作業撰寫

    工具：对比脚本、同花顺；操作：设置脚本模式与路径→运行生成差异报告→截图差异结果→同花顺导出实盘资金曲线→撰写作业（策略+环境+差异+曲线对比）；卡关点：无差异可调整过滤板块或删除回测选股结果

  • 步驟9：策略刪除與後續維護

    工具：客户端策略中心；操作：需删除策略时先设资金比例为0→等待持仓股票全部卖出→删除策略→定期更新内核与客户端；卡关点：不可直接删除持仓策略，避免影响交易

  • 步驟10：問題反饋與功能跟進

    工具：群聊、攻略帖；操作：记录使用中的bug/疑问→群内提问或攻略帖留言→关注客户端功能更新（如研究中心、个股择时可视化）；卡关点：反馈时需附截图与详细描述，便于官方复现

AI 補充建議

【AI 建議】 新手首次实盘建议使用小资金（如1-2万元），优先选择官方精心随机策略，熟悉流程后再进行参数优化或策略魔改，降低试错成本。
【AI 提醒】 数据更新是实盘成功的关键，建议设置双重提醒（手机闹钟+电脑定时任务），避免遗漏更新导致选股异常；首次全量下载数据建议在非交易时段进行，避免占用实盘时间。
【AI 建議】 任务一作业中，差异原因分析需结合实际配置（如过滤板块、模拟资金），避免无依据猜测；资金曲线对比可标注关键时间节点（如换仓日、大盘异动日），让作业更具说服力。
【AI 提醒】 QMT版本需严格遵循客户经理建议，切勿随意升级或降级，否则可能导致与客户端不兼容；客户端实盘参数设置后建议截图备份，避免后续误操作修改。
【AI 建議】 策略资金分配建议分散配置（如3-4个策略组），避免单一策略占比过高导致风险集中；换仓时间重新生成后，建议记录关键策略的换仓时段，便于后续监控。
【AI 提醒】 实盘过程中若遇到日志报错，优先截图保存报错信息，联系林奇或彩虹研究员时提供截图+详细操作步骤，可大幅提高问题解决效率；避免在交易时段频繁修改配置，防止影响交易执行。
